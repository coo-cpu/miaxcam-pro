# Python 基础语法与句法对照表

本手册旨在为初学者（特别是具有 C 语言背景的学习者）提供 Python 核心语法的快速索引。

## 1. 基础规范

| 特性               | Python 规则                    | 备注 (对比 C)                   |
| ------------------ | ------------------------------ | ------------------------------- |
| **代码块**   | **缩进** （通常 4 空格） | C 使用 `{}`，Python 强制缩进  |
| **行尾**     | 不需要分号 `;`               | 换行即表示语句结束              |
| **变量声明** | 动态类型，直接赋值 `x = 5`   | 不需要 `int`,`double`等前缀 |
| **注释**     | `# 单行`或 `""" 多行 """`  | C 使用 `//`或 `/* */`       |

## 2. 数据类型

| 类型             | 示例                      | 说明                            |
| ---------------- | ------------------------- | ------------------------------- |
| **整数**   | `age = 20`              | 无溢出限制，自动处理大整数      |
| **浮点数** | `pi = 3.14`             | 相当于 C 的 `double`          |
| **字符串** | `"Hello"`或 `'Hello'` | 支持单/双引号，支持多行 `"""` |
| **布尔值** | `True`,`False`        | **注意首字母大写**        |
| **空值**   | `None`                  | 相当于 C 的 `NULL`            |

## 3. 核心容器 (数据结构)

| 容器                   | 定义示例                 | 特点                         |
| ---------------------- | ------------------------ | ---------------------------- |
| **列表 (List)**  | `nums = [1, 2, 3]`     | 相当于动态数组，可存不同类型 |
| **元组 (Tuple)** | `point = (10, 20)`     | **不可变**的列表       |
| **字典 (Dict)**  | `d = {"key": "value"}` | 键值对映射 (Hash Map)        |
| **集合 (Set)**   | `s = {1, 2, 3}`        | 元素唯一，无序               |

## 4. 控制流句法

### 条件判断 (if-elif-else)

```
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

### 循环 (for & while)

```
# 遍历序列
for i in range(5):  # 0, 1, 2, 3, 4
    print(i)

# 遍历列表
fruits = ["apple", "banana"]
for fruit in fruits:
    print(fruit)

# 条件循环
while count < 5:
    count += 1
```

## 5. 函数定义 (def)

Python 函数不需要声明原型，直接定义即可。

```
def add_numbers(a, b=10):  # 支持默认参数
    """计算两数之和"""
    result = a + b
    return result

# 调用
ans = add_numbers(5, 20)
```

## 6. Pythonic 特色句法

### 列表推导式 (List Comprehension)

快速生成列表的优雅方式。

```
# 生成 0-9 的平方列表
squares = [x**2 for x in range(10)]
```

### 切片 (Slicing)

获取序列的一部分。

```
s = "Python"
print(s[0:2])  # "Py" (含头不含尾)
print(s[::-1]) # "nohtyP" (反转字符串)
```

### 解包 (Unpacking)

```
x, y = (10, 20)
```

## 7. 常用内置函数

* `print()`: 输出到控制台。
* `len()`: 返回容器长度。
* `type()`: 查看变量类型。
* `input()`: 获取用户输入（返回字符串）。
* `range(start, stop, step)`: 生成数字序列。

## 8. 与 C 语言的核心差异总结

1. **内存管理** ：Python 自动垃圾回收，不需要 `malloc` 和 `free`。
2. **指针** ：Python 没有显式指针，所有对象引用由底层处理。
3. **强类型但动态** ：变量不需要声明类型，但 `1 + "2"` 会报错。
4. **库引用** ：使用 `import` 替代 `#include`。

## 9. 数据科学核心库 (常用函数)

使用前需先导入：

```
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
```

### A. NumPy (矩阵运算与数值计算)

**什么时候用？** 需要处理大量数字、进行线性代数运算、或处理多维数组（Tensor）时。

* `np.array([1, 2, 3])`: 创建数组。
* `np.arange(0, 10, 0.1)`: 创建指定步长的等差数列（比 `range` 强大，支持浮点步长）。
* `np.zeros((3, 3))`, `np.ones()`: 创建全 0 或全 1 矩阵。
* `arr.reshape(new_shape)`: 改变数组形状。
* **注意事项** ：尽量避免在 NumPy 数组上使用 Python 的 `for` 循环，应使用 NumPy 的 **向量化运算** （如 `a + b` 直接完成两个数组对应元素相加），速度快百倍。

### B. Pandas (数据处理与分析)

**什么时候用？** 处理类似 Excel、CSV 的表格数据时。它是数据清理和预处理的核心。

* `pd.read_csv('file.csv')`: 读取数据。
* `df.head()`: 查看数据前几行。
* `df.describe()`: 查看统计学摘要（均值、标准差等）。
* `df['column_name']`: 选取某一列。
* `df.dropna()`: 删除缺失值。
* **注意事项** ：Pandas 的操作通常返回新对象（Copy），如果想在原对象上修改，需注意部分函数有 `inplace=True` 参数。

### C. Matplotlib (绘图与可视化)

**什么时候用？** 需要将数据转化为图表（折线图、散点图、直方图）时。

* `plt.plot(x, y)`: 绘制折线图。
* `plt.scatter(x, y)`: 绘制散点图。
* `plt.title()`, `plt.xlabel()`, `plt.ylabel()`: 设置标题与坐标轴标签。
* `plt.legend()`: 显示图例。
* `plt.show()`: **关键！** 渲染并显示图表。
* **注意事项** ：在 Jupyter Notebook 中使用时，可能需要加上 `%matplotlib inline` 确保图片能嵌入在页面内。

## 10. 综合使用建议

1. **流程** ：通常用 **Pandas** 加载并清洗数据，用 **NumPy** 进行数学建模计算，最后用 **Matplotlib** 展示结果。
2. **效率** ：如果能用 NumPy/Pandas 的内置函数完成的操作，永远不要手动写循环去做。
